# DADOS DO PROJETO

## Qual o nome do seu sistema?
    The Card trader

## Qual projeto você vai desenvolver?
Um sistema para troca e venda de cartas de jogos TCG.

## Qual é o objetivo do seu sistema?
Permite que jogadores de TCG tenham mais facilidade para trocar, vender ou doar cartas.

## Para quem ele é feito (público-alvo)?
Jogadores de TCG (pokemon, magic, yu-gi-oh ...)

## Qual problema real seu sistema pretende resolver?
A confusão para trocar ou vender cartas de TCG em grupos de whatsapp. Muitas pessoas falando ao mesmo tempo, muitas propostas e a dificuldade de informar caso alguma carta não esteja mais disponível

## Quais serão as principais funções do sistema?
- cadastro de usuários e login
- alterar configurações da conta e interface.
- Cadastrar cartas ou deck para vender/trocar/doar
- listar cartas/decks que estejam a venda ou disponívels para troca
- criar proposta de venda ou troca de cartas 
- Editar configuraçẽos para venda ou troca da carta (por parte de quem adiciona a carta no sistma)
- definir regras para a venda ou troca de cartas
- histórico de ações do usuário 
- histórico das propotas para a carta/deck

## Quantos tipos de usuários diferentes o sistema terá?
Usuário comum e administrador

## Quais telas/interfaces você pretende que o sistema tenha?
- Criar conta
- Login
- Recuperar senha

## Há algum motivo pessoal, acadêmico ou profissional que te incentivou a desenvolver esse sistema?
_Motivo acadêmico_: E um projeto criativo que explora uma boa gama de funções para um sistema web, facilitando a prática e exemplificação do framework em um contexto real.

_Motivo pessoal_: Vou montar um decks de cartas no futuro e não quero confusão

## Quais informações (dados) o sistema precisará armazenar?
- Dados de login do usuário
- histórico de ações feitas pelo usuário no sistema
- informações das cartas e divisão por decks salvas no sistema (imagnes inclusas)
- Histórico das atividades durante a troca/venda das cartas

## O sistema será utilizado em computador, celular ou ambos?

- Será responsivo para interfaces mobile (PWA desejável para mobile para uso de câmera)

## Você pretende usar alguma tecnologia específica além do que foi visto em aula?
- Bootstrap para a estética geral e responsividade
- PWA básico para carregamento rápido e uso de câmera em iphones (se precisar)
- Websockets para mensagens em tempo real (!!! ultima coisa a se fazer)

## Quais são as principais dificuldades que você imagina encontrar no desenvolvimento?
- Ajustar o fluxo de uso do sistema para que fique simples e rápido (precisa ser mais simples que enviar fotos e mensgens no whatsapp)
